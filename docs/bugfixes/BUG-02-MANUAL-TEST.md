# BUG-02 Minecraft 26.3 人工测试清单

## 1. 测试范围与安全要求

以下项目均为 **MANUAL**。自动化测试与成品 JAR 启动探针不能替代这些真实 GUI、保存和重启操作。

- 被测分支：`fix/bug02-mc-26.3`。
- 被测 JAR：`build/libs/visual-keymap-26.3-1.4.0.jar`。
- SHA-256：`7E854A6D9FEDAE327ECB884AFCD97228AFA0BD0CD536C699E13AEFF9AEB5182C`。
- 使用 Minecraft 26.3、Fabric Loader 0.20.1、Fabric API 0.165.0+26.3。
- 必须复制一个独立游戏目录和配置目录，不得直接使用正常游玩的实例。
- 所有快照测试都使用副本；不要修改 26.2 原始 `export1.json` 或私人配置原件。
- 每轮测试前保存 `options.txt`、相关 MaLiLib 配置及快照副本的 SHA-256；失败时保留 `logs/latest.log`、截图或录像。

推荐先在完整四模组环境执行 M-01、M-02、M-04、M-05，再执行唯一身份、取消和不支持键码测试，以减少重启次数。

## 2. M-01 原样导入不再产生 12 条错误预览

前置：安装 Visual Keymap、MaLiLib，以及能注册四条 `malilib/openConfigGui` 的 Bedrock-Miner、Item Scroller、MiniHUD、Tweakeroo 26.3 兼容版本；导入文件使用真实 `export1.json` 的测试副本。

1. 启动独立实例，确认四条热键当前分别对应快照中的 `Enter+7`、`Enter+6`、`Enter+3`、`Enter+1`。
2. 打开 Visual Keymap，导出一份新的 version 1 快照。
3. 不修改任何键位，立即导入刚导出的文件。
4. 再导入真实 `export1.json` 的测试副本。
5. 重复“导出后立即导入”三次。

PASS：每次均不出现 12 条错误变更，不调用确认写入流程，四条 live binding 和配置文件语义保持不变。若界面显示任何实际差异，或任一配置哈希在无保存理由时变化，则 FAIL。

证据：每次导入前后截图或连续录像、四条绑定截图、导出文件、相关配置与哈希。

## 3. M-02 完全退出与重启持久化

1. 完成 M-01 后通过正常菜单完全退出游戏，确认 Java/Minecraft 进程结束。
2. 重新启动同一测试实例。
3. 检查四条 MaLiLib 绑定及 Visual Keymap 显示。
4. 再导出一次 version 1 快照，并按 provider、ID、keys、modifiers 的语义与退出前文件比较。

PASS：重启后没有新增变化；同名绑定的实际 keys 与退出前一致。JSON 字段顺序或格式差异不单独构成失败。

证据：退出前后配置副本、再导出的快照、`latest.log`、绑定截图。

## 4. M-03 唯一身份正常恢复

前置：选择一个在当前 provider 内 `(provider, binding ID)` 唯一的普通键位，先导出快照。

1. 记录原按键并导出快照。
2. 在 GUI 中把该键位改成另一个安全按键并保存。
3. 导入旧快照。
4. 确认预览只包含预期差异，点击确认。
5. 完全退出并重启。

PASS：只恢复目标键位；其他键位不变；重启后仍保持恢复值。

## 5. M-04 重复 ID 的歧义提示与默认安全性

1. 以四条 `malilib/openConfigGui` 为基线导出快照。
2. 只修改其中一条绑定为一个未被另外三条使用的新组合并保存。
3. 导入旧快照。
4. 检查预览标题、警告及每个 `[歧义]` 标记。
5. 检查每行是否能辨认当前类别/模组、热键名称、当前 keys 与快照目标 keys。
6. 不勾选任何候选，点击确认。

PASS：歧义候选默认全部未选择；警告明确说明 version 1 缺少来源身份；确认后零写入，修改后的绑定和其余绑定均不变。

## 6. M-05 手工一对一恢复

1. 从 M-04 的歧义预览重新开始。
2. 选择正确的 live binding 与快照目标组合。
3. 再选择一个共享同一 live binding 或同一快照目标的候选，观察前一项是否自动取消。
4. 最终只保留正确候选并确认。
5. 保存、完全退出并重启。

PASS：任意时刻一个 live binding 最多接受一个目标，一条快照记录最多应用到一个 live binding；确认时仅目标绑定写入一次；重启后结果正确。

## 7. M-06 取消操作无副作用

1. 制造一个唯一差异和一个重复 ID 歧义场景。
2. 分别打开导入预览，勾选候选后点击取消或按 Esc。
3. 关闭 Visual Keymap，完全退出并重启。

PASS：取消前后 live binding、`options.txt` 和第三方配置语义不变；未触发 provider 保存造成的键位变化。

## 8. M-07 F25 tombstone 与未知扩展键

仅操作快照副本。准备两份 version 1 测试文件：一份把某个可识别 binding 的 `keys` 改为 `[314]`（F25 tombstone），另一份改为未分配扩展值 `[16842751]`（`0x0100FFFF`）。不要把这些文件用于正常实例。

1. 分别导入两份测试文件。
2. 检查目标值显示为不可用或不支持。
3. 尝试点击候选复选框和确认。
4. 取消并重启。

PASS：候选不可选择、不可应用，不会映射为其他有效按键；若它同时属于重复 ID 歧义，歧义选择也不能绕过不可应用保护；重启后原绑定不变。

## 9. M-08 Provider 共存回归

前置：MaLiLib/Tweakeroo、CommandKeys、Mod Menu 全部安装。

1. 从原生控制菜单和 Mod Menu 分别打开 Visual Keymap。
2. 检查 Minecraft、MaLiLib、CommandKeys provider 均存在且顺序正常。
3. 完成一次正常唯一键位导入；检查 CommandKeys 仍不出现在 version 1 导出中。
4. 修改并保存一个 MaLiLib 键位和一个 CommandKeys 宏绑定，完全退出并重启。

PASS：BUG-02 预览逻辑不影响 provider 枚举、普通编辑或保存；CommandKeys 的既有“不参与快照”语义不变。
