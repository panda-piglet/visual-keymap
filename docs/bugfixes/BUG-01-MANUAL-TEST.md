## 2. 建议执行顺序

### M-01 原始非法 JSON

- 模组：P1（Visual Keymap 与必要 Fabric 组件）。
- 操作：打开 Visual Keymap，导入私人证据 `invalid.json` 的测试副本。
- 预期：客户端不崩溃；显示简短的本地化“导入失败”提示；不进入导入预览；提示中不显示原始 JSON、完整用户路径或 Java 堆栈。
- PASS：上述条件全部满足，且现有键位未变化。
- FAIL：崩溃、出现预览、键位改变、泄露原始内容/路径/堆栈中的任一项。

### M-02 提示关闭与返回

- 操作：分别用提示按钮和 Esc 关闭错误提示。
- 预期：两种方式均返回原来的 Visual Keymap 屏幕；屏幕可继续搜索、编辑或再次导入。
- PASS：没有空白屏幕、错误父屏幕或卡死。

### M-03 连续无效输入

- 操作：依次导入空文件、截断 JSON、`null`、字符串/数字/数组根节点、缺少 `bindings` 的对象、错误字段类型文件。
- 预期：每次均安全拒绝并显示同类提示；客户端和 Visual Keymap 始终可继续使用；没有绑定变化。
- PASS：所有输入都满足预期；逐个记录实际提示和日志异常类型。

### M-04 文件选择取消

- 操作：打开导入文件对话框后取消，不选择文件。
- 预期：返回 Visual Keymap；不显示“无效快照”提示；不进入预览；不改变或保存绑定。
- PASS：取消与解析失败明确区分。

### M-05 失败后立即正常导入

- 操作：先触发一次非法导入并关闭提示，不退出 Visual Keymap；随后导入有效 version 1 快照，检查预览并确认。
- 预期：有效快照正常进入预览，所选差异按既有规则应用和保存。
- PASS：先前失败不污染后续导入状态。

### M-06 BUG-02 重复 ID 回归

- 模组：P3 或包含原四个 MaLiLib 热键来源的等效环境。
- 操作：导入 BUG-02 的重复 `(provider, id)` 快照副本。
- 预期：仍使用安全歧义预览；歧义项默认不应用；人工选择保持一对一；原样导入不再出现 12 条错误变化。
- PASS：BUG-02 已验收行为全部保持。

### M-07 完全退出与配置无副作用

- 操作：在只执行无效导入和取消、不确认任何有效导入的会话中退出游戏；比较配置文件并重新启动。
- 预期：`options.txt` 与相关 provider 配置的语义和哈希均未因失败导入改变，重启后的绑定保持原值。
- PASS：没有持久化副作用。若其他模组会自动改写格式，应进行语义比较并记录原因。

### M-08 英文提示

- 操作：将语言设为 English (US)，重复 M-01/M-02。
- 预期：标题为简洁的 `Import Failed`，正文说明文件不是有效快照；返回行为正常。
- PASS：文本完整、可读且不泄露敏感内容。

### M-09 简体中文提示

- 操作：将语言设为简体中文，重复 M-01/M-02。
- 预期：标题为 `导入失败`，正文简洁说明文件不是有效快照；返回行为正常。
- PASS：文本完整、可读且不泄露敏感内容。

### M-10 日志与依赖组合

- 模组：至少 P1，再使用 P5（MaLiLib/Tweakeroo、CommandKeys、Mod Menu 全部存在）重复 M-01、M-05。
- 操作：保存两次运行的 `latest.log`。
- 预期：日志记录具体 `JsonParseException`/`IOException` 和开发者可诊断堆栈；界面不显示堆栈；没有 `Unexpected error` 客户端崩溃；P5 各 provider 仍可加载。
- PASS：日志足以诊断且用户界面保持脱敏，所有 provider 共存正常。
